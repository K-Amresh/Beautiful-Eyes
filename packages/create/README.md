# @beautiful-eyes/create

Scaffold a [Beautiful Eyes](https://beautiful-eyes.netlify.app/) app with webpack, TypeScript, and a first counter already wired.

```sh
npx @beautiful-eyes/create my-app
cd my-app
npm start
```

Same tool via npm:

```sh
npm create @beautiful-eyes my-app
```

The generated project depends on `@beautiful-eyes/core`, `@beautiful-eyes/template-compiler`, and `@beautiful-eyes/dynamic-import`.

- Docs: [beautiful-eyes.netlify.app](https://beautiful-eyes.netlify.app/) (Get Started tab)
- Source: [github.com/AmKreta/Beautiful-Eyes](https://github.com/AmKreta/Beautiful-Eyes/tree/master/packages/create)
